# Telegram Bot для временного доступа к домофону

Бот для управления временным доступом к домофону через Telegram.

## Функционал

### Для администраторов:
- **Интерактивное создание доступов** через пошаговый диалог с inline-кнопками
- Просмотр всех доступов с пагинацией и inline-кнопками для управления
- Отзыв (ревоук) доступов одним нажатием кнопки
- Главное меню с удобной навигацией

**Интерфейс администратора:**
- Главное меню с кнопками для всех действий
- **Создание доступа** - пошаговый диалог:
  1. Выбор количества использований (1, 5, 10 или ввод своего значения)
  2. Выбор срока действия (бессрочно, 1, 7, 30 дней или ввод своего значения)
  3. Ввод комментария (опционально)
  4. Подтверждение и создание
- **Список доступов** - просмотр с пагинацией, кнопками для отзыва каждого доступа
- Все действия доступны через inline-кнопки, без необходимости ввода команд

**Команды администратора (для обратной совместимости):**
- `/create_access` - начать создание доступа через диалог
- `/list_accesses` - открыть список доступов

### Для пользователей:
- **Интерактивное меню** с кнопками для всех действий
- Открытие двери домофона одним нажатием кнопки
- Просмотр статуса своего доступа с удобным интерфейсом

**Интерфейс пользователя:**
- Главное меню с кнопками:
  - 🚪 Открыть дверь
  - 📊 Статус доступа
- Все действия доступны через inline-кнопки

**Команды пользователя:**
- `/start <token>` - активация доступа по ссылке (токен передается автоматически)
- `/open` - открыть дверь домофона (также доступно через кнопку)
- `/status` - просмотреть статус доступа (также доступно через кнопку)

## Установка и запуск

### Локальный запуск

1. Скопируйте `.env.example` в `.env` и заполните необходимые переменные:
   ```bash
   cp .env.example .env
   ```

2. Отредактируйте `.env` и укажите:
   - `TELEGRAM_BOT_TOKEN` - получите у [@BotFather](https://t.me/BotFather)
   - `ADMIN_IDS` - ваши Telegram ID (через запятую)
   - `INTERCOM_ENDPOINT` - эндпоинт API домофона
   - `INTERCOM_TOKEN` - Bearer токен для API домофона
   - `BOT_BASE_URL` - URL вашего бота в формате `https://t.me/your_bot_username`

3. Запустите через Docker Compose:
   ```bash
   docker-compose up -d
   ```

4. Проверьте логи:
   ```bash
   docker-compose logs -f bot
   ```

### Миграция базы данных

Если вы обновляете существующую базу данных (например, после изменения типов данных для Telegram ID), выполните миграцию:

**Вариант 1: Автоматическая миграция (рекомендуется)**
Бот автоматически попытается выполнить миграцию при запуске. Если это не сработало, используйте вариант 2.

**Вариант 2: Ручная миграция**
```bash
docker-compose exec bot python migrate_telegram_ids.py
```

Или если контейнер не запущен:
```bash
# Остановите бота
docker-compose stop bot

# Запустите миграцию
docker-compose run --rm bot python migrate_telegram_ids.py

# Запустите бота снова
docker-compose up -d
```

**Вариант 3: Пересоздание базы данных (если данных нет или можно их потерять)**
```bash
# Остановите все контейнеры и удалите volumes
docker-compose down -v

# Запустите заново
docker-compose up -d
```

**Ошибка "integer out of range"**
Если вы видите эту ошибку, это означает, что база данных использует старый тип Integer для Telegram ID. Выполните миграцию одним из способов выше.

### Развертывание через GitHub Actions

При пуше в ветку `main` или `master` автоматически собирается Docker образ и пушится в GitHub Container Registry.

Для использования образа из registry:
```yaml
# В docker-compose.yml замените build на image
services:
  bot:
    image: ghcr.io/your-username/intercom-bot:latest
    # ... остальная конфигурация
```

## Переменные окружения

- `TELEGRAM_BOT_TOKEN` - токен Telegram бота
- `ADMIN_IDS` - ID администраторов (через запятую)
- `INTERCOM_ENDPOINT` - PUT эндпоинт для открытия двери
- `INTERCOM_TOKEN` - Bearer токен для авторизации в API домофона
- `DATABASE_URL` - строка подключения к PostgreSQL
- `BOT_BASE_URL` - базовый URL бота (для генерации ссылок)
